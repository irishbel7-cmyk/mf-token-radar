Method, in full

Eligibility. A protocol joins the ranked board only if its snapshot record carries no token (both gecko_id and symbol null), its category is not Bridge, Canonical Bridge, Liquid Staking, Liquid Restaking, Restaked BTC or CEX, its name does not end in a version marker, carries no whole word “wrapped”, “staked” or “staking”, and does not begin with an exchange name (Binance, Coinbase, Bybit, Kraken, Bitget, OKX, Bitfinex, Gemini). That mirrors the house watchlist rule, minus its TVL floor and minus the parent-protocol check, which the snapshot does not carry. The board therefore holds the 40 watchlist protocols plus genuine pre-token protocols below the floor.

Implied value. Take the median market-cap / TVL ratio across protocols that already trade with both figures positive — computed from this snapshot at run time, never hardcoded — and multiply the protocol’s TVL by it. Then apply three factors: growth, 1 + the 7-day TVL change clamped to −40%…+80% (no change reported counts as 1); maturity, 0.7 + 0.3 × (1 − e^(−age in days / 365)), or 0.85 when no listing date is recorded; breadth, 1 + 0.05 per extra chain up to five. Rank by implied value descending; ties break by higher TVL, then slug ascending. Ranks run exactly 1 to N.

One honest edge case. Sentora Curator carries about $2.76B of TVL and ranks near the top, yet it is not on the house watchlist — the house rule uses a parent record the snapshot does not carry. It passes every eligibility check on the fields the snapshot does carry, so it stays on the board, and the rule is stated here rather than hidden.

Caveat. Implied value is this entry’s own claim about what a token would be worth if the protocol traded like the median protocol that already does. It is not a prediction of whether or when any token is issued, and a DefiLlama record of “no token” is not proof that none exists.
